# Fortune Cookie Wisdom for Developers

One original fortune-cookie line for a software developer, written for the
[make.fun](https://make.fun) bounty
"Fortune Cookie Wisdom for Developers".

> Your future self is already debugging the code you are about to write.

A single balanced sentence that lands in one breath: true about a
developer's day (every line you write becomes tomorrow's debugging session),
with a quiet twist — the bug hunt has already started before the code exists.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```

The program writes exactly one line (70 characters, no trailing newline) to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), and validates the entry
is 1–120 characters and a single line before writing.
